# Opus GSAP 动效优化设计

日期：2026-08-07
状态：已确认

## 目标

在不削弱 Opus 轻量、专注写作定位的前提下，为应用加入鲜明、活泼且可控的动效。动效覆盖应用外壳、文档切换和编辑内容，但不得干扰普通输入、光标移动、滚动、文件安全流程或辅助功能。

## 设计原则

- 使用 GSAP 编排需要时序、错峰或中断控制的动画。
- CSS 继续负责颜色、悬停、布局和简单状态过渡。
- GSAP 仅动画 `transform` 与 `opacity` / `autoAlpha`；不使用 JS 高频动画宽度、高度或位置布局属性。
- 动效由状态变化触发，不由普通键入、光标移动或滚动持续触发。
- 所有动画可中断、可清理，并尊重 `prefers-reduced-motion`。
- 保留现有未提交的 CSS 动效工作，实施时只消除与 GSAP 重复控制同一属性的部分。

## 技术方案

采用“GSAP 关键编排 + CSS 基础反馈”的混合方案。新增 `gsap` 与 `@gsap/react` 依赖，并在 `src/motion/` 建立统一动效层：

- GSAP 与 `useGSAP` 的一次性注册入口。
- 统一的时长、缓动和错峰参数。
- reduced-motion 查询与降级规则。
- 可复用的应用、面板、弹窗、列表和编辑内容动画函数。
- 编辑内容动画的目标筛选与数量上限。

React 动画使用组件 ref 作为作用域，并通过 `useGSAP` 或显式 GSAP context 清理。CodeMirror 生成的命令式 DOM 由编辑器内部的受限适配层处理，不把编辑器内容同步回 React，也不改变 `DocumentPort` 或文档状态模型。

## 组件边界

### AppShell

负责应用启动、空白页、左右侧栏、状态提示和文档面板切换。侧栏宽度仍由现有 React 状态与 CSS 布局控制；GSAP 只动画面板内部的位移、缩放与透明度。拖拽调整侧栏宽度时暂停相关动效。

### TabList

负责标签新增时的错峰进入和当前标签切换反馈。快速连续切换使用覆盖策略接管旧 tween，不积压动画队列。关闭操作不得延迟控制器的保存确认或关闭流程。

### Dialogs

所有 `.dialog-overlay` 共用一致的入场编排：遮罩淡入、对话框弹入、标题/正文/操作按钮错峰出现。现有焦点陷阱、Escape 语义、`aria-modal` 和恢复对话框不可取消的规则保持不变。

### MarkdownEditor

编辑器在阅读模式挂载或切换时，动画当前视口内有限数量的内容目标。目标包括普通行、标题、表格、数学公式和图片；首屏最多选择 16 个目标。编辑模式的 CodeMirror 宿主和可编辑行不执行 GSAP transform/opacity，保证输入、选区和键盘时序稳定。

CodeMirror 虚拟滚动后来创建的旧内容不重复执行入场动画。阅读模式后来创建的图片、公式或表格可以执行一次独立弹入；编辑模式不安装 widget observer。大文档轻量模式跳过内容错峰，只保留壳层动效。

## 动效语言

- 应用启动：标题栏与编辑区域由 `y: 10px`、`scale: 0.985` 淡入，约 420ms；侧栏内容随后错峰进入。
- 侧栏：面板从对应窗口边缘弹入，标题、标签与文件项以约 35–45ms 间隔错峰出现；关闭反馈更短。
- 标签：活动项使用轻微横向位移与回弹；新增项从左侧弹入；按压反馈允许更明显的缩放。
- 文档切换：编辑模式保持 CodeMirror 立即可编辑；阅读模式的新内容以约 320–400ms 上浮进入，内容分层错峰。
- 编辑内容：阅读模式标题位移强于普通行；图片使用缩放加淡入；表格与公式短距离上浮。
- 弹窗：遮罩快速淡入，对话框由 `scale: 0.9`、`y: 18px` 弹出，内部信息依次出现。
- 提示条：从窗口上沿滑入，关闭时快速上移消失。
- 核心缓动使用 `power3.out`，强调性入口可使用适量 `back.out(...)`；不使用无限循环、持续晃动或指针跟随。

具体数值集中在动效层，组件不得自行重复定义常量。实施阶段可在自动化与本机视觉验收中小幅调整数值，但不得改变上述触发范围和可访问性约束。

## 状态与生命周期

- 每个组件的动画限定在自己的 DOM 作用域。
- 组件卸载、依赖变化或媒体查询变化时清理 tween、timeline 和 context。
- 对快速重复操作使用 `overwrite: "auto"` 或等价的可中断 timeline 策略。
- 不通过动画回调提交文档状态；业务状态先完成，动效只反映结果。
- 目标缺失或组件在动画前卸载时安全跳过，不抛出用户可见错误。
- reduced-motion 模式取消位移、缩放与错峰，仅保留极短淡入或立即显示。

## 性能约束

- 仅动画合成友好的 transform 与透明度。
- 只为实际参与动画的短生命周期节点使用 `will-change`，完成后清理。
- 编辑内容入口最多处理当前视口 16 个目标。
- 大文档轻量模式不执行内容级 stagger。
- 不为每次输入创建 tween，不在编辑模式的 CodeMirror DOM 上写入 transform/opacity，不在滚动事件中持续查询或写入布局。
- 不让 CSS 和 GSAP 同时控制同一节点的 transform 或 opacity。

## 测试与验收

单元与组件测试覆盖：

- 统一动效参数与目标上限。
- reduced-motion 降级。
- 组件卸载和依赖变化后的清理。
- 侧栏、标签、弹窗与文档切换的正确触发。
- 普通输入、光标移动和滚动不创建内容动画。
- 大文档轻量模式跳过内容错峰。

实施后运行：

```sh
npm test
npm run build
```

根据涉及流程补跑 Playwright 关键用例。手工验收连续快速切换标签、侧栏与弹窗，确认无排队、卡顿、闪烁或控制台错误；检查编辑输入和滚动稳定；检查系统“减少动态效果”开启后无明显位移或缩放。

## 非目标

- 不加入滚动驱动特效、视差、鼠标跟随或持续背景动画。
- 不修改文件读写、恢复、冲突处理或工作区数据流。
- 不为动画重写 CodeMirror 渲染机制。
- 不要求所有 CSS transition 都迁移到 GSAP。
